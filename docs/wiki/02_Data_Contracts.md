# 02 Data Contracts

Full per-field documentation lives in `docs/data_contracts.md`. This file is the quick-reference summary.

## Claim Object (`claims.json`)

Schema: `schemas/claim.schema.json`

Key fields: `claim_text`, `claim_type`, `metric`, `period`, `value`, `unit`, `source_status`, `confidence`, `extraction_method`, `ticker`

Known limitation: `period` may be wrong due to `_nearest_year()` ±200 char heuristic in multi-year sentences. Treat as approximate until PR2.

## Fact Table Row (`fact_table.csv`)

Schema: `schemas/fact_row.schema.json`

Key fields: `ticker`, `claim_type`, `metric`, `period`, `claimed_value`, `verified_value`, `source`, `verification_status`, `notes`

`verification_status` values: `verified`, `incorrect`, `unsupported`, `not_machine_verifiable`, `SOURCE_CONFLICT`

Note: `incorrect` may include `PERIOD_ERROR` or `UNIT_ERROR` — do not interpret as confirmed hallucination without manual review.

## Reliability Scorecard (`reliability_scorecard.json`)

Schema: `schemas/reliability_scorecard.schema.json`

Key metrics:
- SCR = source_coverage_rate = (verified + incorrect) / total
- PSCR = primary_source_coverage_rate = verified / machine_verifiable
- UCR = unsupported_claim_rate = unsupported / total
- ICR = incorrect_claim_rate = incorrect / machine_verifiable

## Recommendation Object (`recommendation.json`)

Schema: `schemas/recommendation.schema.json`

Key fields: `ticker`, `rating.value` (BUY/HOLD/SELL), `price_target.value`, `expected_return_pct.value`, `top_catalysts`, `top_risks`, `key_assumptions`, `unsupported_recommendation_components`

Status: not yet generated by pipeline — planned for PR2 via `recommendation_extractor_v1.txt`.

## Gate Decision (`gate_decision.json`)

Schema: `schemas/gate_decision.schema.json`

`decision` values: `PASS`, `HUMAN_REVIEW`, `FAIL`

Status: not yet generated — planned for PR3.

## Experiment Manifest (`experiment_manifest.json`)

Schema: `schemas/experiment_manifest.schema.json`

Reproducibility record for each batch run. Status: planned for PR3.

## Run Metadata (`run_metadata.json`)

Schema: `schemas/run_metadata.schema.json`

Per-LLM-call provenance: model_name, provider, temperature, prompt_version, prompt_hash, input_hash, output_hash, fallback_used.

Status: designed, not yet wired into pipeline — planned for PR2.
